# Vertical-Rice-Seedling-Monitoring
Official implementation of the paper: "End-Edge-Cloud Collaborative Group Phenotype Recognition and Diagnosis for Rice Seedlings in Vertical Rice Seedlings Cultivation".
## Code and Data

- Source code is available in the `main` branch.
- Images and annotations are available in the
  [master branch](https://github.com/subeici/Vertical-Rice-Seedling-Monitoring/tree/master).

To download the data, switch to the `master` branch and select
**Code → Download ZIP**.
